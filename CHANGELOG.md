# Changelog

Все даты — по времени компьютера сборщика. Правило: ни одна дата
в этом файле не может быть позже сегодняшнего дня (проверяется
скриптом `temp/build-beta.ps1` перед релизом).

## [0.1.0-beta.2] - 2026-09-29

Связи, исполнение графа, фикс ресайза.

### Added
- Связи между блоками: гнезда «вход/выход», тяга мышью от выхода
  ко входу, SVG-слой с кривыми и заглушками в чужие категории.
- Живая проверка графа: ошибки, предупреждения о циклах, инфо
  о связях сквозь категории; бейдж и раздел «Связи» в панели.
- Исполнение графа: кнопка запуска и Ctrl+Enter, топологический
  порядок, циклы до стабильности или лимита, Журнал-приёмник,
  клики Действий эмитят значения, один прогон — одна точка Ctrl+Z.
- Схема файла v3 (порты, связи, настройки лимита); файлы v1/v2
  загружаются с миграцией.

### Fixed
- Ресайз за верхнюю/левую грань двигал противоположный край:
  теперь грань следует за курсором, противоположная зафиксирована.
  Плюс упор координат в ноль поля.

## [0.1.0-beta.1] - 2026-09-29

Бета: первая запускаемая сборка Windows + исправление хоткеев.

### Fixed
- Горячие клавиши (`Ctrl+Z` / `Ctrl+N` / `Ctrl+Y`, `G`, `[`, `]`)
  работают на русской раскладке: проверка идёт по `e.code`
  (физическая клавиша), а не по `e.key`.

### Added
- Портативная сборка Windows: `npm run dist:win`
  (electron-builder, target `dir` → `release/win-unpacked/`,
  запуск через `Transformer.exe`).
- Кэш сборки лежит в `temp/eb-cache` внутри программы,
  а не на системном диске.
- Этот CHANGELOG.

## [0.1.0] - 2026-09-28

Первый релиз: оболочка с двойной разметкой (8px / 64px).

### Added
- Окно Electron без системной рамки, своя панель в сетке.
- Двойная разметка: снап к малым квадратам с притяжением к крупным,
  выравнивание по граням соседей с направляющими.
- Рельс категорий с регулируемой границей, рабочее поле.
- Блоки 5 типов из контекстного меню, название сразу.
- Развёртка: обычный / свёрнутый / на всё поле.
- Сохранение раскладки: атомарная запись, автосейв, проверка файла.
- Свои типы блоков, панель свойств, отмена `Ctrl+Z`.
